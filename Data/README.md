# Data Files

## Raw Data

The raw folder contains the original World Bank electricity-access and GDP-per-capita datasets.

## Cleaned Data

The cleaned folder contains the combined dataset used for the analysis.

## Final Variables

* country_code: Three-letter country code
* country_name: Country or territory name
* year: Year of the observation
* electricity_access: Percentage of the population with access to electricity
* gdp_per_capita: GDP per person in constant 2015 US dollars
